How to use skoolHarbor

Applies to version 1.3.0 · Chrome & Firefox

1. Install and pin the extension

Add skoolHarbor from the Chrome Web Store or Firefox Add-ons. Pin the icon to your toolbar so it is one click away while you work through a course.

On first run you will be asked to start the free trial (3 downloads) or sign in as an existing user. No credit card is required for the trial — it is handled by ExtensionPay.

2. Open a lesson and play the video

Navigate to a Skool lesson or post, or a Vimeo, Loom or Wistia page. Press play. The extension watches the network for the video manifest, so the stream has to actually start loading before it can be detected.

If nothing appears, let the video buffer for a second or two, then reopen the popup. On Skool, some lessons load the player only after you scroll it into view.

3. Build the list as you browse

Every video skoolHarbor detects is added to a list that persists as you move between lesson pages. Open several lessons in a module, let each player start, and the popup will show all of them together. Use Clear List in the popup header to start fresh.

4. Choose quality

When a source offers multiple renditions (common on Vimeo and Skool's CDN), each list entry has a quality selector. Pick the resolution you want before downloading. If only one rendition exists, the selector is fixed to that.

5. Select and download

  • Tick the checkbox on each video you want, or use Select All.
  • Click Download Selected.
  • skoolHarbor fetches the HLS segments, muxes them into a single MP4 in the browser, and hands the finished file to your browser's download manager.
  • A combined progress bar shows the queue status. Use Cancel Queue to stop remaining items.
Downloads run one at a time by design — muxing a long lesson video is CPU and memory work, and serialising it keeps large batches stable.

6. Embedded YouTube videos

YouTube clips embedded in Skool lessons are listed too, but they are not downloaded through the browser. Instead skoolHarbor gives you a ready-to-copy yt-dlp command:

yt-dlp -f "bv*+ba/b" "https://www.youtube.com/watch?v=VIDEO_ID"

Paste it into a terminal where yt-dlp is installed. This keeps skoolHarbor's in-browser downloader focused on the streaming hosts it handles natively.

Redeeming an AppSumo code

  1. Open the popup. If you are not already premium, an Have an AppSumo code? button appears.
  2. Click it, paste your code (format SKOO-XXXX-XXXX-XXXX), and press Redeem.
  3. The code activates on that browser immediately — no account, no separate login.

Troubleshooting

SymptomFix
No video detectedMake sure playback actually started. Reload the page, play again, reopen the popup.
Download stalls near the endLong videos need memory to mux. Close other heavy tabs and retry that single item.
Quality list only shows one optionThat source only publishes one rendition. Nothing to change.
Trial status not updatingOpen the popup, use Sign In / Existing User to re-sync with ExtensionPay.
Skool CDN video failsSkool occasionally rotates its CDN headers. Update to the latest version — see Releases.

Still stuck? Open an issue on GitHub.
