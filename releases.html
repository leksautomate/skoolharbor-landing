Releases

Latest: v1.3.0 — Chrome Web Store & Firefox Add-ons

v1.3.0 — current

  • Firefox port. Full Manifest V3 build for Firefox 142+, published on addons.mozilla.org alongside the Chrome release.
  • AppSumo code redemption built into the popup — activate a lifetime code on the browser directly, no account.
  • Review prompt shown once after your first successful download or a week after install.
  • Hardened Skool video-CDN request headers for more reliable detection on native lessons.
  • Accessibility and content-security-policy fixes for add-on store review.

Earlier

Detection & download core

  • Per-site detectors for Skool (native player + video.skool.com CDN), Vimeo, Loom and Wistia.
  • HLS (.m3u8) parsing with per-rendition quality selection.
  • In-browser muxing of HLS segments into a single MP4 — no server, no ffmpeg install.
  • Detected-video list that persists across lesson pages, with Clear List.
  • Batch selection and a serial download queue with combined progress and Cancel Queue.
  • Embedded-YouTube surfacing with a ready-to-copy yt-dlp command.

Licensing

  • 3-download free trial via ExtensionPay, with email registration and trial-status display.
  • Monthly, yearly and lifetime plans through ExtensionPay / Stripe checkout.
  • Manage / cancel link surfaced in the popup for active subscribers.

Roadmap

Directional, not a commitment — order and scope may change.
  • Auto-advance through a Skool module, collecting every lesson video without manual page-by-page play.
  • Optional per-download subtitle/caption fetch where the host exposes one.
  • Configurable filename templates (course / module / lesson).
  • Retry-failed-items action on the queue.

Install or update from the Chrome Web Store or Firefox Add-ons.
